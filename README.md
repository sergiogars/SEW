# Página desarrollada a lo largo de la asignatura del Grado en Ingenieria Informática Del Software.
## Temática y contenido.
A lo largo de esta página web se verá información que tiene que ver con [La Vuelta a España 2026](https://www.lavuelta.es/es/) . Actualmente cuenta con la información 
personal del ciclista Carlos Rodriguez y de su equipo, NETCOMPANY INEOS CYCLING TEAM.
Respecto al equipo se mostrará la alineación de sus corredores en formato carta, con información básica sobre cada uno de ellos y una foto personal suya. 
La página web cuenta también con un apartado de meteorología, una etapa de las 21 etapas de [La Vuelta a España 2026](https://www.lavuelta.es/es/). En este
caso concreto se habla y se informa de la Etapa número 7.

Como bonus adicional, se cuenta con una sección de juegos donde actualmente hay un cuestionario sobre la información de la etapa de esta web.

Actualmente esta desplegado en [Github Pages](https://sergiogars.github.io/SEW/).

## Tecnologías utilizadas
Se usaron tanto JavaScript, CSS y HTML5 para la parte web y Python para tratar los XML y sacar la información e informes necesarios para completar la práctica, como pueden ser los pdfs de Altimetría y Planimetría, y se comprobó la usabilidad, adaptabilidad y accesibilidad con los estándares web actuales para [HTML5](https://validator.w3.org/nu/#file),
 [CSS](https://jigsaw.w3.org/css-validator/) y [Contraste de colores](https://caniuse.com/) . Además de haber usado Google Lighthouse, [Wave](http://wave.webaim.org/) y [Achecks](https://achecks.org/achecker/)
